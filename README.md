# Gradia

Gradia is a machine learning project built from scratch with Python.

The goal of this project is to understand how machine learning models work internally instead of relying immediately on high-level libraries.

## Current features

* Linear regression
* Logistic regression
* Gradient descent
* Loss functions
* Model predictions
* Accuracy evaluation
* Comparison with Scikit-learn

## Technologies

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Project goal

Gradia is primarily a learning project.

The objective is to implement machine learning algorithms manually in order to understand concepts such as:

* weights and bias
* predictions
* loss functions
* derivatives
* gradient descent
* optimization
* classification

Scikit-learn is used mainly as a reference to compare the results of the implementations.
